# BioBeetlia

**BioBeetlia is a bio-inspired environmental monitoring project designed to explore how robotics and software can support urban tree monitoring.**

The project combines a physical robotic prototype with a mobile platform for tree registration, inspections and environmental data organization.

---

## Overview

BioBeetlia started as a question:

**How could a small robotic system help make urban tree monitoring more continuous, organized and accessible?**

From that idea, I began developing two connected parts:

- a robotic prototype for environmental sensing and field experimentation;
- a mobile platform for registering trees, recording inspections and organizing monitoring data.

The current version is still under development and serves as a proof of concept for the integration between hardware, software and environmental monitoring.

---

## Mobile platform

The BioBeetlia app was developed with:

- React Native
- Expo
- TypeScript
- AsyncStorage

Current features include:

- individual tree registration;
- tree profiles;
- inspection records;
- environmental monitoring interface;
- organization of tree data and observations.

---

## Robotic prototype

The physical prototype is used to explore:

- sensor integration;
- robotic mobility;
- environmental data collection;
- hardware and software communication;
- future bio-inspired redesigns.

The current prototype is not the final robotic architecture. It is a first engineering version used to understand limitations and guide the next iterations of the project.

Current development
BioBeetlia is currently being redesigned toward a more compact, lightweight and efficient robotic architecture.
Future development includes:
- improved sensor integration;
- environmental data analysis;
- stronger communication between the robot and the app;
- new robotic prototypes;
- field testing in urban tree environments.
Why BioBeetlia?
Urban trees are often planted, but monitoring after planting can be irregular or fragmented.
BioBeetlia explores a different approach: combining robotics, sensing and digital tools into a single system designed specifically for urban arborization monitoring.
